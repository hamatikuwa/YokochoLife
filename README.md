# ツトムの挑戦状 〜地獄谷商店街の夕日〜

夜の裏路地を歩き回りながら、からおけスナック経営・ぼったくりバー経営(+チンピラとの乱闘)・
野グソまでこなす、脱力系フリーワールドゲーム。ブラウザだけで動作し、スマホでそのまま遊べます。

## 遊び方

`index.html` を開くだけ。ローカルで確認する場合はブラウザで直接開くか、
簡易サーバーを立てて `http://localhost:8000/` 等にアクセスしてください。

```bash
python3 -m http.server 8000
```

- 左下十字キー: 移動
- 画面右側ドラッグ: 視点回転
- 右下ボタン: 会話/攻撃/トイレ等のアクション
- 跳ボタン: ジャンプ
- 十字キー上の枠: 主人公の顔を正面から映し続ける顔カム(ワイプ)

## ディレクトリ構成

- `index.html` — 公開用のビルド済み単一ファイル(GitHub Pagesはこれを配信する)
- `src/` — 編集用のソース一式(`index.html` / `style.css` / `game.js` / `lib/three.min.js`)
- `build.py` — `src/` の内容を結合して `index.html` を再生成するスクリプト

`src/` 配下を編集したら、必ず `python3 build.py` を実行してから公開用 `index.html` をコミットしてください。
